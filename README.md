# useful_functions

My useful function collections and moduled it.

標準ライブラリの枠を超えた高精度な数学演算、低レイヤのアルゴリズム、および日常的なシステム制御を単一のパッケージに統合した、開発者向けの強力なユーティリティモジュールです。

特に `Fraction`（分数）をベースとした高精度演算アルゴリズムを多数実装しており、浮動小数点誤差を回避しながら厳密な計算を行うことが可能です。

## 🚀 主な機能と特徴

### 1. 高精度な数学・解析機能 (`Calcurations` クラス)
標準の `math` モジュールでは対応できない、特大桁の計算や分数ベースの厳密な演算を提供します。
* **円周率(π)の計算**: Ramanujan、Chudnovsky、Gauss-Legendreなど、13種類もの算出アルゴリズムを実装。
* **超越関数**: テイラー展開などの級数を用いた `exp`, `ln`, `sin`, `cos`, `arctan` などの独自計算（Fractionベース）。
* **素数・数論アルゴリズム**: 高速な素数判定（複数の最適化ロジック搭載）、素因数分解、ユークリッドの互除法(GCD)、フィボナッチ数列、アッカーマン関数、テトレーション計算。

### 2. 低レイヤ・データフォーマット操作
ビットレベルの解析や、浮動小数点の内部構造にアクセスする関数群です。
* **IEEE 754変換**: 浮動小数点数(float)とIEEE 754形式のバイナリ文字列・バイト列表現を相互に変換 (`to_ieee754`, `from_ieee754`)。
* **高精度な誤差解析**: `infinite_precision` による厳密な仮数・指数の分離や、浮動小数点の丸め誤差計算 (`float_error`)。
* **エンコーディング**: Burrows-Wheeler変換 (BWT) のエンコード・デコード処理や、XORを用いたハッシュ計算。

### 3. 実用的なシステム・ファイルユーティリティ
ファイル操作やネットワーク、データ整形など、面倒な定型処理を簡略化します。
* **単位・サイズ変換**: バイト数を人間が読みやすいSI接頭辞（KiB, MiB, GiB等）に変換する `BytesToSIUnit` や、単位文字列のパース機能。
* **ファイル操作**: 再帰的なディレクトリサイズの取得 (`get_dir_size`) や、ファイル保存時の上書きを自動回避してリネームする `NoOverride` 機能。
* **ネットワーク・時間**: MACアドレスやIPアドレスの即時取得。タイムスタンプからISO8601形式への厳密な独自変換 (`timestamp2ISO8601`)。

## 💡 想定されるユースケース
* **アルゴリズム研究・競技プログラミング**: 素数生成や巨大数の処理、素因数分解を自前で実装せずに素早く呼び出したいとき。
* **高精度計算が求められる分野**: 浮動小数点誤差を許容できない金融計算や、純粋数学的な検証用途。
* **日常的な自動化スクリプト**: ネットワーク情報の一発取得や、ディレクトリサイズの集計、生成ファイルの上書き防止などをサクッと組み込みたいとき。
